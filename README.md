# calculadora-web

Projeto de uma calculadora moderna e responsiva desenvolvida para praticar conceitos fundamentais do desenvolvimento web front-end.

---

### 💻 Tecnologias Utilizadas

- **HTML5:** Estrutura semântica da interface.
- **CSS3:** Estilização moderna (Grid Layout, Flexbox e variáveis visuais).
- **JavaScript:** Manipulação de DOM e lógica de operações matemáticas.

---

### 🚀 Funcionalidades

- Operações básicas: Soma, Subtração, Multiplicação e Divisão.
- Botão de exclusão individual (apagar último caractere).
- Botão para limpar todo o visor.
- Interface escura (*Dark Mode*) otimizada para uso em computadores e celulares.
